# Changelog

All notable changes to Weave will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project structure and documentation
- Core pattern recognition framework design
- API-first architecture with FastAPI
- CLI interface design with natural language support
- Container-based execution environment design
- Comprehensive development documentation
- Software development best practices guide

### Changed
- Pivoted from domain-specific to pattern-based approach
- Renamed project from "Claude Orchestrator" to "Weave"
- Shifted from CLI orchestration to API-first platform

### Security
- Planned container isolation for all executions
- Context-aware safety framework design

## [0.1.0-alpha] - TBD

### Added
- Basic pattern detection system
- Simple container execution
- Initial CLI prototype
- Core API endpoints
- First 3-5 working patterns

### Documentation
- Getting started guide
- API documentation
- Pattern development guide
