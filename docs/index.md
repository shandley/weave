## What is Weave?

Weave recognizes that all technical work follows patterns. Instead of building domain-specific tools, Weave provides a universal platform that:

- **Detects patterns** in your work descriptions
- **Executes safely** in isolated containers
- **Learns and adapts** from successful executions
- **Enables 24/7 work** with progressive trust

## Key Concepts

### Patterns
Work patterns are the building blocks of Weave. Examples include:
- **Exploratory**: Try multiple approaches to solve a problem
- **Pipeline**: Process data through sequential steps
- **Generative**: Create new code or documents
- **Analytical**: Understand and visualize data

### Universal Operations
All work reduces to eight fundamental operations:
- Load, Transform, Analyze, Generate, Execute, Validate, Iterate, Persist

### Safety Framework
Every execution happens in isolated containers with:
- Context-aware constraints
- Rollback capabilities
- Comprehensive audit trails
